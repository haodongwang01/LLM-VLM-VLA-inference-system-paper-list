 - **WorldKV: Efficient World Memory with World Retrieval and Compression**
(ArXiv 2026.05) [[paper]](https://arxiv.org/abs/2605.22718) WorldKV is a training-free framework that achieves efficient long-term consistency in video world models through World Retrieval, which selectively restores viewpoint-relevant KV-cache chunks, and World Compression, which reduces storage by pruning redundant tokens based on key-key similarity. 

 - **X-cache：Cross-Chunk Block Caching for Few-Step Autoregressive World Models Inference**
(ArXiv 2026.04) [[paper]](https://arxiv.org/abs/2604.20289) X-Cache innovatively accelerates few-step autoregressive world models by caching DiT block residuals across consecutive generation chunks—rather than across denoising steps—leveraging the spatio-temporal continuity of the physical world.

 - **Timestep Embedding Tells: It's Time to Cache for Video Diffusion Model**
(CVPR 2025) [[paper]](https://arxiv.org/abs/2411.19108) TeaCache is a training-free caching approach that leverages timestep-embedding modulated noisy inputs as a computationally efficient indicator to estimate output fluctuations, allowing for adaptive feature reuse that significantly accelerates video diffusion inference with negligible impact on visual quality.

- **WorldCache: Accelerating World Models for Free via Heterogeneous Token Caching**
(ICML 2026) [[paper]](https://arxiv.org/abs/2603.06331) WorldCache introduces Curvature-guided Heterogeneous Token Prediction (CHTP) and Chaotic-prioritized Adaptive Skipping (CAS), effectively addressing acceleration bottlenecks caused by multi-modal token heterogeneity and non-stationary temporal dynamics in diffusion world models without requiring any training.
