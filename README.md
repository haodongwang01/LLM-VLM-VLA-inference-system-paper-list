# LLM-VLM-VLA-inference-system-paper-list

本仓库用于整理基础模型推理系统相关论文、资料与调研笔记，重点关注 LLM、VLM、VLA 等模型在高效推理与系统优化中的代表性工作。

当前内容主要围绕以下方向持续更新：

- LLM/VLM/VLA 推理系统与服务框架
- GPU、CPU-GPU、端侧设备上的推理优化
- KV Cache 管理、稀疏注意力、剪枝与投机解码
- 后训练量化、量化训练与量化推理系统
- VLA 推理中的 CoT、多任务并行、异步推理与具身智能系统评测

本仓库希望作为一个按主题分类的论文入口，方便快速查找相关工作、跟踪近期进展，并为后续调研、选题和系统实现提供参考。
